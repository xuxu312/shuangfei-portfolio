## 2. 历史性能与网络问题

5.4 的受限网络测试使用 Chrome 153、390×844、DPR 1、冷缓存、CPU 4 倍降速、150ms 延迟和约 200,000 字节/秒下载条件。记录中的首页与详情 LCP 优化前约为 6.116 秒与 6.140 秒，优化后三次复测中位数均约 1.472 秒。

首次完全离线访问无法下载页面，保留为 V1 不支持离线。内部导航故障、未知地址和正常联网时的服务器错误分别处理，不以“离线不支持”掩盖其他问题。
