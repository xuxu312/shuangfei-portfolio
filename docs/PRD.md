# 个人综合作品集网站 · 产品需求

版本：仓库整理版，2026-10-26。依据原 PRD V1.2 及此后用户确认的范围调整整理，反映当前候选网站，不重新打开已完成的需求讨论。

## 1. 产品目标与用户

以“双非电源仔”为公开名称，集中展示真实作品、工程实践、AI 应用探索与精选内容。网站首先让访问者看懂作品、个人贡献和公开联系方法，同时便于长期更新。

主要面向工程与技术爱好者、内容读者、潜在合作伙伴及本人。第一版的核心路径是：首页了解方向 → 查看作品 → 阅读详情与证据 → 返回或查看联系信息。

## 2. 第一版范围

| 功能 | 当前要求与状态 | 验收要点 |
| --- | --- | --- |
| 首页与导航 | 简短 Hero、作品、工具、分享、关于我、联系；已实现 | 入口有效，内容层次清楚，介绍不占满首屏 |
| 精选作品 | 当前展示一个真实 MMC 项目；支持多项目、排序及取消精选 | 卡片信息准确；取消精选不等于撤下详情 |
| 项目详情 | 独立稳定地址，说明用途、贡献、事实及证据；已实现 | 直达、刷新、返回正常，不把 MMC 专用内容写死在所有项目上 |
| 我的工具 | 当前没有公开工具；已实现空说明和未来卡片能力 | 工具与作品使用同一主数据，不能编造使用入口 |
| 精选分享 | 当前没有整理好的真实内容；已实现空说明和未来卡片能力 | 后续可放文章或视频的标题、简介、平台与真实链接 |
| 关于我 | 介绍电气工程背景及关注方向；已验收 | 不加入未经确认的经历，不重新带入真名 |
| 联系方式 | 展示并复制小红书昵称“双非电源仔” | 未提供的邮箱、平台链接和按钮整项隐藏；实际账号可找到性待人工核实 |

第一版不要求三个以上作品。现有一个经过验收的真实项目足以作为首版内容，不以测试条目补齐数量。

## 3. 内容规则

### 项目

每个公开项目应有标题、简述、分类或标签、封面及替代文字、稳定 slug、项目状态、个人贡献和可公开的证据。按实际材料选择事实列表、证据图片、总览图或外链，不要求每个项目拥有相同的实验章节。

- `visibility` 控制是否公开；未发布材料不进入正式数据或资源目录。
- `featured` 控制是否在首页精选区域出现。
- `order` 控制展示顺序，不改变作品地址。
- `slug` 是稳定地址标识；改标题不自动改 slug。
- 新增公开项目时，卡片、详情、元信息与静态预渲染必须一致更新。
- 撤下内容时同时检查数据、页面与图片文件，不能仅隐藏入口。

### 工具与分享

没有真实内容时保留简洁说明，有记录后展示真实卡片。工具来自项目主记录；分享可关联项目但不重复维护项目详情。未经核实的链接不显示，暂不做自动抓取、账号同步或站内文章系统。

### 公开图片

MMC 目前只使用五个已审核的公开展示文件：两种尺寸的实物照片、波形图、采样图和总览图。降低分辨率和质量，添加中文水印，并对需要保护的区域作不透明遮挡。

网页放大仍只打开公开版。原始高清图片、内部工程资料与处理前后对照文件不进入此仓库。以后新增图片也必须先在本地处理并审核，不能把水印当作敏感信息遮挡。

## 4. 视觉与交互

- 延续用户已认可的白色主体、绿色点缀与现有布局；不重新设计整站。
- 作品优先，标题与正文易读，留白适量，空栏目不使用巨大占位卡片。
- 同时适配桌面与手机；检查 320px、390px 和常用桌面宽度。
- 使用语义化结构、清晰焦点、合理替代文字；关键按钮便于点击和键盘操作。
- 不强制头像、渐变背景、复杂动画；尊重减少动态效果设置。
- 功能检查通过与用户视觉确认分别记录，模拟窄屏不代替手机真机。

## 5. 技术体验与质量要求

1. 主要正文存在于初始预渲染 HTML 中，正常浏览不依赖复杂服务端功能。
2. 首页与详情可以直接访问、刷新和返回；不存在的作品提供准确提示。
3. 首屏关键图片不误用懒加载；其他图片按需延迟加载并预留尺寸。
4. 测试记录与开发页面不得进入正式构建，生产构建必须检查资源和导航数据。
5. 不要求 V1 支持首次断网访问；内部导航故障与正常联网时的异常仍需正确处理。
6. 性能目标可参考 LCP、INP、CLS，但本地模拟数据不能代表真实用户或上线后的表现。
7. 发布前复核隐私与公开范围，不上传密钥、私人资料或实验原图。

## 6. 明确不在第一版内的内容

- 登录、会员、社区、支付、私人任务管理、数据库和网页编辑后台。
- 无真实素材的证书系统、复杂分类筛选、全文搜索、统计后台。
- 将所有 AI 工具开放在线使用，或强制建设完整博客、双语和视频系统。
- PWA、Service Worker 与离线缓存系统。

## 7. 发布与验收边界

已完成：本地网站功能、页面视觉以及公开图片经用户验收。当前整理源码与文档供私有 GitHub 仓库保存。

尚未完成：首次 Git 提交与推送、Vercel 接入、真实网址、线上 404 与缓存、访问保护、真实手机及跨网络访问、联系渠道的实际可达性。

暂时保留 `noindex`，但它不是密码保护。私有 GitHub 仓库也不代表未来部署网址是私有的。公开部署与开放收录均按用户明确授权执行。

当前验收依据与未验证项目见 [验证记录](验证记录.md)。
