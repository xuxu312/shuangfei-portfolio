## 整理原则

本目录根据本地已存在的需求、技术设计、实战记录、开发流程对照表和验收结果整理。保留对理解项目有用的事实与取舍，移除本机绝对路径、原始附件位置、旧身份信息和不适合上传的内部资料。不把用户隐私词表复制进仓库。

这些文件不是原始文档的逐字镜像。原有草稿、完整聊天、实验原图、截图、日志、备份和原始 Git 历史继续留在本地。历史测试数量以原记录为依据；只有标为“本轮实际执行”的项目，才表示此次重新运行。

当前版本优先于早期设想：先发布一个真实项目；关于我使用昵称；不建设网页编辑后台；公开展示版取代原始高清图；Vercel 替代早期的 Cloudflare Direct Upload 候选。尚未完成的线上操作不记作已执行。

## 后续维护

需求改变时更新 PRD，架构或发布方式改变时更新技术设计；每阶段在实战记录中简记计划、实际操作、用户调整、问题、验证和下一步。对照表用于回顾方法差异，不记录每条命令。不要为同一进度再建一份重复的计划表。

本目录不属于网站资源。新增文档也需要检查隐私；私有 GitHub 仓库同样属于云端保存。
