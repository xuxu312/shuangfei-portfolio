## 5.4 整站测试与问题处理

- **原计划：** 测试功能、响应式、图片、元信息、异常、数据隔离、基本性能与可访问性，并在独立目录验证恢复。
- **实际完成：** 记录测试提交与工作区状态，使用生产构建进行浏览器检查，保存首页和 MMC 详情的桌面与窄屏证据；稳定版本恢复验证没有重置当前仓库。
- **问题一：** 首次完全离线时无法加载网页，属于普通静态站的网络条件限制。保留失败证据并标明 V1 不支持离线，不开发 PWA。内部导航中的数据错误另外定位，不能与首次离线混为一谈。
- **问题二：** 原封面较大，受限网络显示偏慢。保留当时原图并生成响应式压缩资源，核实首屏关键图加载策略，按相同条件重复测量。
- **问题三：** 项目总览链接点击高度不足。局部调整到至少 44px，保留外观，并检查窄屏和键盘操作。
- **验证：** 修复后的历史受限网络测量见验证记录；用户认可照片清晰度和页面效果，验收 5.4，保存 `phase-5.4-complete`。
- **仍未验证：** 真机、真实用户性能及线上环境。不把本地实验性能套用到后续公开图片版本。
- **下一步：** 先准备发布条件与公开范围，再决定上传。

## 图片公开处理 Skill 与公开版替换

- **原计划：** 五张 MMC 图片降分辨率、压缩、加中文水印、遮挡敏感区域，不改原图，先审核再替换。
- **实际完成：** 比较两套第三方 Skill 后采用本地 Python/Pillow 专用 Skill，不安装第三方 ImageMagick Skill；工具放在个人 Skill 目录，不混入网站仓库。
- **用户调整：** 不接受生成式处理重绘技术细节，明确使用本地确定性处理。先试一张波形图，保留原始 SHA-256，对候选尺寸和质量进行实际审核；原图尺寸不足时不放大。
- **返工：** 用户认为第一版质量仍偏高，降低一档；两处或四处水印覆盖不足，白底不明显，再调整为大图九处、小图四处以及更可见的颜色。
- **安全边界：** 不透明遮挡设备标识、时间或窗口文字等指定区域；水印不替代遮挡。私有原图和含原图的对照预览仅供本地审核，不上传模型或网站。
- **验证：** Skill 有独立的合成测试，输出检查元数据和原图校验值；用户确认最终密度、颜色与画质后，才替换候选网站的五个公开版文件。
- **替换结果：** 五张图片合计 199,240 字节，旧六个资源地址不再保留；封面、详情及放大入口统一为公开版。最终当批浏览器 54 项通过，保护检查 31 项通过。
- **下一步：** 当前图片无需再处理；新作品按相同流程先本地审核。

## 复盘：哪些方法有效

1. **一个对照表加分类文档。** 总览能看见步骤，细节进入对应文件，避免聊天中失去进度；对照表记录真正的操作和取舍，不只是文件流转。
2. **先原型再扩展。** 先确认白绿风格和一张卡片，减少全站完成后大改的成本。
3. **分组验收与稳定版本。** MMC、联系、工具分享、多作品分别展示和确认；未验收版本不贴已完成标签。
4. **实际浏览器验证。** Playwright 操作发现静态阅读代码难以发现的导航和异常问题；先报告、再修复、再复测。
5. **空状态与隔离夹具。** 没有真实工具也能测试新增能力，同时避免假作品流入正式网站。
6. **原仓库与发布副本分开。** 本地保留完整研究和恢复历史，远程仅保存审核后的资料。

## 复盘：返工与可简化之处

| 问题 | 造成的返工或困惑 | 下次改进 |
| --- | --- | --- |
| 需求、建议与已确认决定混在一起 | AI 提前进入下一阶段，或把可选栏目当必做 | 每份文档区分已确认、待决定和未来设想 |
| 对照表记录文件传递而非开发动作 | 用户需要纠正“实际步骤” | 右栏写输入、判断、实施、验证和变更原因 |
| 多个本地服务地址 | 地址打不开被误认为代码故障 | 每次交付注明页面用途、端口与服务是否运行 |
| 测试按钮与编辑后台含义混淆 | 用户以为可以直接编辑正式内容 | 明确按钮仅切换测试状态，内容由 Codex 更新 |
| 原始照片到发布阶段才处理 | 需替换图片、入口和构建隐私检查 | 首次准备素材时就分开原图、审核版和公开版 |
| 水印先按固定数量处理 | 密度不足、白底看不清，需要重做 | 先试一张，按画面大小与背景确认覆盖和对比度 |
| 把私有检查词写进检查代码 | 检查本身可能泄露要保护的信息 | 专用词表放仓库外，仓库保留通用检查能力 |
| 外部 AI 评审可能落后于本地版本 | 重复讨论或错误应用旧建议 | 先核对版本，针对差异修订，不整稿覆盖 |

保留轻量记录即可，不为套流程增加重复 PLAN、后台或复杂自动化。普通文案修改做相关检查，影响路由、数据和发布范围时才扩大验证。
